# NabdhGram — توسعة المميزات وخارطة الذكاء المحلي

**تحديث نطاق مقترح للتنفيذ بتاريخ 15 نوفمبر 2026.** طلب مالك المشروع البدء بـ NabdhAI في الإصدار الأول وتطويره في كل إصدار لاحق. البنود أدناه متطلبات تطوير وليست مميزات منفذة أو موعودة قبل اختبارات القبول.

## القواعد الحاكمة

- لا تعديل لبروتوكول Telegram أو تجاوز قيود السرعة والخادم أو Premium أو قواعد الحذف وإيصالات القراءة.
- نموذج AI اختياري ومحدود الموارد: Gemini Nano عبر AICore متى دعمه الجهاز، وGemma عبر LiteRT-LM للأجهزة الملائمة، دون تحميل النموذجين في الذاكرة معًا.
- التطبيق يبقى قابلًا للاستخدام الكامل على Android/الأجهزة التي لا تدعم نماذج الذكاء؛ نسخ Telegram الحالية تتطلب minSdk 23، لذا لا تُضاف تبعية AI تتطلب API أعلى إلى الأساس دون عزل وتوافق.
- ليس كل «تعلم» تدريب أوزان: يبدأ التكيف بتفضيلات صريحة محلية مفهومة وقابلة للإيقاف والحذف. لا قراءة للمحادثات أو تدريب على الرسائل تلقائيًا؛ لا حفظ محتوى الحوارات لأغراض الذكاء دون طلب.
- محرك السمعة والأمان مستقل عن النموذج التوليدي؛ لا تقارير «آمن» أو نسب ثقة مختلقة. يتم اختبار العربية والحالات الصحيحة والكاذبة. [معايير NabdhShield](NABDHSHIELD_AI_VERIFICATION_AR.md)
- كل تغيير في ثيم Glass أو Dynamic Monet أو عناصر الحركة قابل للمعاينة والاستعادة؛ ألوان النص/الرموز تمر باختبار تباين، وRTL لا تتغير هندسته تلقائيًا.
- الترجمة عبر خدمة خارجية لا تعمل إلا بعد موافقة واضحة على محتوى الإرسال والجهة والمعالجة. المسار المحلي أفضل عند توفره.
- تصدير إعدادات المستخدم لا يتضمن مفاتيح Telegram أو الجلسات أو الرموز أو مفاتيح التشفير أو رسائل المستخدم. استيراد الإعدادات يتحقق من النسخة والمخطط ويعرض معاينة قبل التطبيق.

## الإصدار 1.0 — البداية المطلوبة، ضمن بوابات قبول واضحة

| المجال | تنفيذ أولي ذو قيمة فعلية | شرط الاعتماد |
| --- | --- | --- |
| NabdhAI Core | واجهة موحدة لاكتشاف الجهاز والنموذج، طلبات اختيارية، إلغاء وفشل آمن؛ ربط **استنتاج حقيقي واحد على الأقل** بحالة استخدام واضحة في Focus Lens أو Catch Me Up قبل تسمية AI مفعّلًا | تجربة استنتاج على جهاز فعلي؛ العربية والذاكرة والحرارة والبطارية، مقارنة نتائج مع المصادر |
| التعلم الشخصي | تفضيلات محلية اختيارية: لغة التلخيص، نمط الاقتراحات، رفض/قبول النتائج؛ بدون تدريب للأوزان أو جمع صامت | إيقاف/مسح/تصدير واستعادة مستقلة للخصوصية، وتعطيل افتراضي |
| NabdhShield | مواصلة التحقق المحلي القابل للتفسير، ومقاييس اختبار صادقة؛ النموذج للتصنيف الإضافي فقط بعد تقييم مستقل | Precision/Recall/false positives بعينات واقعية ومصنفة وليس fixtures مصطنعة |
| Dynamic Monet | وضع اختياري متاح عند Android 12+، مع fallback إلى Glass المعتمد وثيمات Telegram ودرجة تباين مناسبة | لا يغير لون العناصر الرئيسية دون موافقة ولا يخرّب ثيمًا مستوردًا |
| الإعدادات | ترتيب الأقسام المشتركة مع Telegram: المحادثات/المظهر ← الخصوصية ← البيانات ← اللغة، ثم الأقسام الإضافية لـ NabdhShield والإنتاجية والذكاء | قائمة واحدة واضحة، لا نسخ مكرر، ثيمات Glass في صفحة الثيمات وحدها |
| الاتصال والتخزين | تحسينات محلية مأمونة في تنزيل الوسائط والذاكرة المؤقتة، والاعتماد على بروكسي Telegram الأصلي | لا تجاوز لحدود الخادم أو ادعاء تحسين تلقائي غير موجود |
| ترجمة الرسائل الجديدة | مسار اختياري محلي أولًا حيث يتوفر، أو طلب خدمة خارجية بعد موافقة واضحة | لا إرسال صامت، ولا تغيير نص الرسالة الأصلي |
| Settings Backup | تصدير واستيراد محدود لخيارات NabdhGram والثيمات بإذن المستخدم | تصفية الأسرار، فحص مخطط النسخ، ومعاينة قبل التطبيق |

**لا يتم إطلاق v1.0 على أنه AI كامل** لمجرد وجود قائمة خيارات أو سياسة معمارية؛ إن تعذر تحقيق استنتاج فعلي جيد على الأجهزة المستهدفة، تُؤجل العلامة «مدعوم بالذكاء المحلي» لحين تحققها دون تأجيل تحديثات أمان Telegram.

## 1.5 — تخصيص وتفاعل متقدم

- Smart Themes: اقتراح ألوان النظام/الخلفيات وتحريك تفاعلات خفيفة، مع وضع تقليل الحركة وعدم تحويل النماذج إلى محرك رسم.
- Swipe Actions قابلة للتخصيص دون تعارض مع سحب Telegram أو الاتجاه RTL.
- قفل محلي اختياري للمحادثات برمز/بصمة مع حماية محتوى التطبيقات الأخيرة؛ لا ادعاء عزل المحادثات عن خوادم Telegram.
- Channel Feed يعرض منشورات القنوات الموجودة في حساب المستخدم ويعيد رابط المصدر ويحترم ترتيب/صلاحيات الوصول، دون نسخ الرسائل خارجيًا.
- تحسين الترجمة السياقية والبحث المحلي، وإدارة تفضيلات AI وإمكانية نقلها (دون بيانات المحادثات).
- بروكسي مسبق الإعداد لاتصالات Telegram فقط إذا أمكن عزله ضمن بنية Telegram دون VPN عام أو تسريب DNS أو التلاعب بالترافيك.

## 2.0 — وسائل الإعلام والمتصفح

- CameraX مع Camera2 Interop عند الحاجة بدل استبدال كاميرا Telegram على جميع الأجهزة؛ دعم اختياري للقدرات التي يعرضها المصنع، مع اختبار إذن الكاميرا والفيديو والعودة للخلف.
- متصفح داخل التطبيق بوضع منع إعلانات/تعقب اختياري وقواعد قابلة للتحديث، مع احترام عمليات تسجيل الدخول والمواقع والتعامل بحذر مع WebView ومخاطر الروابط.
- نقل الملفات والتحكم في حدود التخزين وعمليات النقل باستخدام واجهات Telegram المسموحة؛ لا تجاوز Premium أو قيود الخادم.
- متابعة أدوات NabdhTools المقررة للفيديو والملفات وPDF.

## 2.5 و3.0 — أتمتة أعمق دون مراقبة خفية

- 2.5: تحسين عمليات الكاميرا/الميديا، إدارة التنزيلات، وقاعدة معرفة شخصية محلية وتخصيص نماذج أصغر عند إثبات القيمة.
- 3.0: مهام مساعد محلي متعددة الخطوات بعد إذن المستخدم، وعزل الذاكرة والمهام المتكررة، وتقييم إمكان التخصيص/التدريب على الجهاز إذا دعمه العتاد ووافق المستخدم.

## مطابقة إعدادات Telegram

المصدر المثبت Telegram 13.2.2 يعرض الأقسام: الحساب، المحادثات، الخصوصية، الإشعارات، البيانات، المجلدات، الأجهزة، توفير الطاقة، اللغة. تبقى هذه الصفحات الأصلية حيث هي. شاشة «إعدادات نبض جرام» **لا تستنسخها**؛ تُرتّب الأقسام التي لديها فعليًا إعدادات مقابلة وفق ترتيب Telegram النسبي، وتضع الإضافات المستقلة في الأسفل. هذه هي الخطوة البرمجية الأولى في هذا التحديث؛ ليست إعادة كتابة التصميم الأصلي.
