# نبض جرام — تسوية مراجعة Work الأمنية والهندسية للإصدار التجريبي النهائي
**التاريخ:** 17 نوفمبر 2026  
**الهدف:** اعتماد نسخة `Release` تجريبية موقّعة للرفع إلى Google Play، مع الحفاظ على وظائف Telegram المعتمدة.

## مرجع التقرير
المراجعة المستلمة شملت `main@baf3518` و`release@bf30715`، وكلاهما يسبق آخر تعديلات إزالة Twemoji وتحصين الخصوصية. حالة كل بند هنا **حالة كود**، ولا تمثل اختبارًا مستقلًا على هاتف أو قياسًا فعليًا للذاكرة والطاقة.

| رقم | الخطورة | النتيجة في أحدث فرع الإصدار | حالة القبول |
|---|---|---|---|
| 01 | عالية | **مُحصَّن بالمصدر:** تصدير سبع خدمات داخلية مغلق، مستقبل SMS محمي بإذن المرسل من Google، والصلاحيات القديمة محددة النطاق، عبر `apply-nabdh-security-hardening.py` | فحص المانيفست المدمج واختبار تسجيل الدخول والإشعارات والمكالمات في APK موقّع |
| 02 | عالية | **سياسة إنتاجية أضيفت:** قواعد `apply-nabdh-private-backup.py` تُطبّق على Release فقط: `allowBackup=false`، `fullBackupContent=false`، وقواعد استبعاد التخزين الخاص والسحابة والنقل بين الأجهزة على Android 12+. تتضمن الجلسات `saved_tokens` و`saved_tokens_login` وصور `NabdhCameraFiles` المخزنة في `getFilesDir()` | يُختبر النقل والاستعادة على جهاز اختباري؛ ينتج عنه عدم إمكانية الاستعادة الآلية لبيانات التطبيق، وليس فقدان الجلسة في الترقية العادية الموقعة |
| 03 | عالية محتملة | **مقيَّد بالمخاطر، لا يُدّعى حله:** Telegram الأصلي يسمح `usesCleartextTraffic=true` لدعم روابط HTTP داخل المتصفح. لم تُعطّل هذه الخاصية حتى لا ينكسر المتصفح أو بعض الروابط؛ يجب ضمان عدم تمرير بيانات الحساب الحساسة عبر HTTP عبر اختبار حركة الشبكة | إجراء تحقق ديناميكي قبل الإطلاق العام، ومراجعة نطاقات HTTP قبل التفكير في عزلها |
| 04 | عالية محتملة | **أُصلح بالمصدر:** تُصفَّر `LaunchActivity.instance` و`staticInstanceForAlerts` من `onDestroy()` بشرط أن يشيرا إلى **هذه** الشاشة فقط، حتى لا يمحو تدمير الشاشة القديمة مرجع شاشة أحدث | اختبار تدوير/إعادة إنشاء الشاشة وتحليل heap للتأكد من عدم الاحتجاز |
| 05 | عالية | **أُصلح بالمصدر:** إزالة `worker.join(1500)` من UI thread؛ `quitSafely()` يعمل دون انتظار؛ كل رد صورة يرفض جيل الكاميرا القديم بعد الإيقاف أو تغيير الكاميرا | اختبار Camera2 بالعودة السريعة والإلغاء والتقاط الصور والتعليق/ANR |
| 06 | متوسطة | **أُزيل بالكامل:** محرك Twemoji وخيارها وملفات البناء/التنزيل السابقة. فقط Telegram وAndroid؛ فحص CI يمنع عودة رسومها إلى APK | تحديث نسخة كانت تختار Twemoji وفحص الحزمة وحجمها؛ عدم المساس بملفات المستخدم |
| 07 | متوسطة | **إصلاحات مخبأة موجودة:** كود الخطوط يتجنب اجتياز الشجرة لكل إطار ويخزن مفاتيح التطبيق؛ كود التمويه يحتفظ بصورة جدارية مموهة ولا يحسبها لكل فقاعة. إنشاء أول صورة تمويه داخل الرسم لم يثبت أثره عمليًا؛ لا إصلاح تخميني قد يغير تصميم Glass | قياس `gfxinfo` وFrame Timeline وCPU/PSS على هاتف، خصوصًا التمرير وتغيير الخط/الثيم |
| 08 | متوسطة | **تحسين بالمصدر:** حفظ مجموعة حوارات القفل بذاكرة محدودة وتحديثها عند تغيير `AtomicFile`، مع فحص بيانات الملف؛ حماية `_unreadable` fail-closed. وقت `SystemClock.elapsedRealtime` يمنع تقصير مهلة PIN أثناء تشغيل العملية مع إبقاء مدة جدارية للمحاولات عبر إعادة التشغيل | اختبار قفل الإشعارات، PIN، تغيير ساعة الهاتف، تبديل الحسابات، إعادة تشغيل الهاتف. تعديل الساعة بعد إعادة التشغيل يظل قيد تحقق |
| 09 | متوسطة | **مُحصَّن بالمصدر:** إلغاء `MusicPlayerService` للمهمة المكررة ووقفها بعد عدد محدود من المحاولات وتحرير جلسة الوسائط والموارد | دورة تشغيل/إيقاف 30 مرة مع قياس heap والبطارية |

## القبول الفني
1. النجاح في `Foundation`، و`Pinned Telegram Preflight`، و`Android Debug` **لنفس SHA النهائي**؛ نتائج أي SHA سابق لا تثبت آخر التعديل.
2. الدمج عبر PR #79 **بعد نجاح CI** فقط. التوقيع يجب أن يستخدم **مفتاح المالك الأصلي** من GitHub secrets؛ لا يستبدل بمفتاح تجريبي.
3. تشغيل سير Release يدويًا من `main` لإنتاج APK إنتاجي وAAB موقّع؛ ثم التحقق من SHA-256، اسم الحزمة `net.nabdhserv.nabdhgram`، API 36، ABI، توافق صفحات 16KB، والصلاحيات المدمجة. رفض البناء عند اختلاف المفتاح/المعرف أو غياب قواعد خصوصية Release.
4. اختبار تثبيت Release الصافي وترقية Release بنفس توقيع الإنتاج، وإشعارات Firebase والمكالمات وحماية PIN والكاميرا وخطوط RTL قبل الرفع للاختبار الداخلي في Google Play.
5. مراجعة سياسة الخصوصية وData Safety وGPL وطلبات Play ذات الحساسية (خدمات المقدمة، المنبّهات الدقيقة، إشعارات ملء الشاشة). لا توجد شهادة كاملة بعدم تسرب الذاكرة/المعلومات من فحص ساكن فقط.

## حدود نطاق الإصدار
لم يُضف إعلان كاذب بتوفر NabdhAI أو محرك ذكاء اصطناعي جديد، ولم تُفعّل مراقبة تلقائية للمحادثات. شبكة Telegram ونظام Glass والخطوط والإيموجي المدمجة محفوظة. يُجرى اختبار سلوك النسخ الاحتياطي **على Release** تحديدًا لأن سياسة الأمان الجديدة خاصة به.
