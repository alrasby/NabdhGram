# NabdhGram V1 — سجل الاستئناف المؤكد (2026-11-15)

## تحديث التصميم والبنية بعد مراجعة فيديو المستخدم 129319.mp4
- أُزيلت قائمة الأدوات الإنجليزية الخام من الصفحة الرئيسية؛ توزّعت الأدوات بحسب الفئات المعتمدة: المتصفح والكاميرا تحت **الشبكة والوسائط**، موجز القنوات تحت **الإنتاجية**، وقفل المحادثات وإجراءات السحب تحت **الخصوصية والمراسلة**، وNabdhAI في قسم الذكاء الحالي.
- أنشئت صفوف إعدادات زجاجية موحّدة: 5 أيقونات vector قابلة للتلوين، عنوان عربي/إنجليزي مقتضب، وصف ثانوي، ارتفاع لمس 76dp، تباين بالألوان الأصلية لثيم Telegram وخط rmedium، مع احترام لغة Telegram وRTL.
- أُضيف شريط عنوان ورجوع موحد للمتصفح والكاميرا والموجز وإدارة PIN وNabdhAI عبر `NabdhToolUi`، وفُصل شريط أدوات المتصفح لحل تزاحم الأزرار. حوار Swipe Actions أصبح Native Telegram AlertDialog بدل حوار Android غير المتناسق.
- تجنّب إعادة بناء شاشات تسجيل الدخول أو قائمة الدردشات أو المزايا المعتمدة؛ لا تغييرات في بيانات الرسائل أو الجلسات أو الشبكة.
- فحص المصدر المستحدث `scripts/check-nabdh-tool-settings-layout.py` يفشل مبكرًا عند رجوع القوائم الخام أو فقدان موارد الأيقونات أو الترجمات أو شريط العنوان المشترك.
- هذه التعديلات لا تُعد مُختبرة على جهاز حتى ينجح Build جديد لـPR #79 بعد الدمج ويُراجع الفيديو/الصور التالية في الوضعين الفاتح والداكن.

## ما نُفّذ في PR #82 (يلزم فحص المصدر والبناء)
- مسار Camera2: حفظ JPEG كما سبق، ثم مشاركة URI المحتوى عبر `ACTION_SEND` إلى `LaunchActivity` كي يستخدم Telegram واجهة اختيار المستلم والإرسال الأصلية. Android 29+ عبر `MediaStore`، وAndroid 23–28 عبر `FileProvider` الأصلي مع `FLAG_GRANT_READ_URI_PERMISSION`.
- واجهات كاميرا/متصفح/إدارة PIN/NabdhAI تستخدم العربية مع واجهة Telegram RTL، وألوان Theme وGlass التكيفية بدل خلفيات سوداء ثابتة؛ أزرار أدوات نبض جرام تُترجم عبر `LocaleController`.
- WebView يرفض غير HTTP/HTTPS في مساري التحويل الجديد والقديم (Android 23)؛ JavaScript والملفات غير مفعلة افتراضيًا.
- PIN: تنتهي صلاحية إدارة القفل عند `onPause` (حتى عند فقدان التركيز دون توقف كامل)، والعودة تتطلب إعادة إدخال الرمز. تُلغى جلسة فتح الدردشة عند `onPause` **بعد** إكمال تأكيد القراءة المشروع، لمنع إعادة استخدام تصريح PIN بعد العودة من الخلفية.
- تستخدم حماية شاشة المحادثة `FlagSecureReason` الأصلية المرجعية عوضًا عن `Window.clearFlags` الذي قد يلغي حماية Telegram العامة.
- اختبارات مصدر جديدة: `scripts/check-nabdh-camera-browser.py`، وتوسيع `check-nabdh-chat-lock-privacy.py` و`check-nabdh-ai-android-compat.py`.

## منع ادعاءات الاكتمال
- وجود مصادر Gemini Nano/Gemma ونجاح APK لا يُثبت تشغيلهما على أجهزة AICore وGemma المتوافقة؛ لا يوجد قياس ذاكرة/حرارة أو دليل استنتاج حقيقي بعد.
- Camera2 مشاركة الصور، WebView، Channel Feed، Swipe Actions، PIN وإشعارات Android تحتاج اختبارًا فعليًا على الهاتف؛ لا تُعد اختبارات المصدر كافية لقبول الأمان.
- Channel Feed لا يجلب جميع منشورات القنوات من الشبكة: يعرض أحدث منشور محفوظ لكل قناة فقط. AI لا يراقب الرسائل والمكالمات ولا يقرأها تلقائيًا.
- الاستقرار: تسجيل الدخول والرسائل والإشعارات والمكالمات والوسائط والتحديث وتغيير الخط والثيم والرموز والـ RTL والبرمجيات على الأجهزة القديمة.
- إصدار Release الموقّع بمفتاح المالك وFirebase اختباره **غير منفّذ**؛ لا يُدمج إلى `main` أو يُعلن V1 عامًا قبل اعتماده.
