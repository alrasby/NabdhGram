## بوابة إصدار إنتاجي يجب إغلاقها
1. نجاح Foundation وPinned Source وGradle على **آخر SHA** (لا يكفي نجاح #687 إن تغيّر المصدر).
2. نتيجة PASS فعلية لكل بند شديد الحساسية أعلاه، مع طراز الجهاز وإصدار Android والملاحظات (دون مشاركة محتوى رسائل أو أسرار).
3. تدقيق البيان الخاص بكل ميزة: **Voice Clarity الحالي رفع خفيف لمستوى صوت الرسالة، لا إزالة ضجيج كاملة؛ التلخيص وNabdhShield بعضهما أدوات صريحة محلية وليس رصدًا تلقائيًا؛ NabdhAI يعتمد على توفر نموذج مناسب**.
4. استعراض متطلبات ترخيص Telegram ومواد Noto/Twemoji/OpenMoji، وسياسة الخصوصية وتوعية المستخدم بأن تنزيل صور الرموز اختياري عبر CDN.
5. حسم مواصفات إصدار/رقم build وتجميد الميزات، ومراجعة PR #79 ثم دمجه فقط بعد الاختبارات.
6. تشغيل صاحب المشروع يدويًا لسير `nabdhgram-signed-release.yml` من `main`، ثم فحص `apksigner`/SHA-256/اسم الحزمة/عدم debuggable/ABI وFirebase.
7. التحقق من **تثبيت نظيف** ومن **ترقية موقعة بنفس مفتاح الإنتاج**. لا تُثبّت Release فوق Debug بتوقيع مختلف دون خطة حفظ بيانات.
8. لا يوجد نشر عام آلي أو إعلان أن النسخة معتمدة قبل إتمام هذه البوابة.

## ملخص الاستئناف
- الإصلاحات المقررة بعد #687: حد لطابور تنزيل الإيموجي، إعادة محاولة مع مهلة بعد فشل الشبكة، مهلة أطول للصورة غير الموجودة؛ كاميرا Camera2 تتخلص من Surface وتتجاهل callbacks القديمة وتستعيد زر الالتقاط بعد فشل الطلب.
