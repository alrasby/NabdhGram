# Telegram Android upstream policy

Source of truth: https://github.com/DrKLO/Telegram

NabdhGram is an independent client and must not imply official Telegram affiliation.

Before importing source:
1. Confirm the current upstream commit and its submodule revisions.
2. Review applicable source and dependency licenses and preserve required notices.
3. Verify Android SDK, NDK, Java, and Gradle requirements from that revision.
4. Configure NabdhGram-specific identity and credentials securely.
5. Keep downstream modifications reviewable for future upstream updates.

Do not import exteraGram code without checking its license and provenance. Do not commit API keys, signing keys, private messages, or user data.
